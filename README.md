# som-na-nuvem
Uma plataforma de streaming de música, "Som na Nuvem", recebe diversas consultas de seus assinantes relacionadas a problemas de acesso, dúvidas sobre planos e dificuldades técnicas. A equipe de suporte está sobrecarregada, e a empresa busca uma solução para agilizar o atendimento e melhorar a experiência do usuário.
